# Product Backlog: CG AI Screenshot Translator

## 1. Completed (已完成项 - 14 项基石与演进特性)
1. **[feat/core] OnnxOcrEngine 单例引擎模式**：通过 `Arc<Mutex<Option<OnnxOcrEngine>>>` 全局惰性单例化，消除重复加载模型导致的内存膨胀与卡顿。
2. **[feat/ocr] WordMerger 文本行聚类重构算法**：针对英文 CG 界面零散词框，实现行间距与重叠度智能合并，准确还原复合单词与短句。
3. **[fix/ocr] 长宽比预处理与变形修复**：修正 SVTR 识别输入图像尺寸重采样逻辑，杜绝窄高/扁宽文本严重拉伸变形引起的识别丢失。
4. **[feat/algo] CLAHE 自适应直方图均衡化预处理**：针对 Blender/Substance 深灰/纯黑暗色 UI 低对比度文本，动态增强明暗边缘对比度。
5. **[chore/model] PP-OCRv4 轻量推理模型权重升级**：热插拔升级至 PP-OCRv4 DBNet 与 SVTR 权重，识别速度提升 25%，准确率显著提高。
6. **[feat/ui] 选区半透明遮罩与聚光灯视觉**：全屏半透明暗化遮罩 (rgba 0.38) + 动态选区高亮框与四角 L 标尺定位。
7. **[feat/ux] 翻译中态阶段化骨架屏动效**：分阶段过渡展示“识别中... -> 翻译中... -> 渲染中...”，消除用户等待焦虑。
8. **[feat/ux] 智能降级感知 Banner 提示**：当指定 LLM 因网络/配额失败自动降级至公共通道或词库时，浮层顶部温和感知告知。
9. **[feat/ui] 浮层顶部多语种快速切换胶囊**：免进设置即可在中/英/日/韩/德/法等 6 种常用语种间一键实时重新翻译。
10. **[feat/ux] 覆盖翻译卡片 Pin 锁定机制**：支持 Ctrl+P 或点击图钉锁定卡片，避免右键或失焦导致误触关闭，支持卡片拖拽与原位保留。
11. **[Stage01/ui] 选区动态十字准星辅助线与坐标气泡**：支持全屏跟随鼠标的细虚线十字准心，实时坐标显示，提升 3D / 界面像素级框选操控手感。
12. **[Stage01/ui] 覆层卡片字号与自适应折行算法**：结合文本行实际宽度与字符密度动态收放字号（10px~22px），支持长文本优雅截断与单卡片 hover 悬浮微工具栏。
13. **[Stage01/ux] 卡片悬浮快捷工具栏与独立操作**：支持单条译文一键复制 (📋)、语音朗读 (🔊)、词库来源标识小标与 Pin 锁定多层光晕。
14. **[Stage01/ux] 全局 F4 极速划词与反馈 Toast**：支持单键 F4 快速唤起与退出划词选区，复制与锁定均具备流光毛玻璃 Toast 及时反馈。

## 3. Next (待排期开发项)

2. **[feat/gpu] DirectML GPU 加速后端适配**：在 Windows 平台上启用 DirectML 执行提供程序，显卡硬件加速推理。
3. **[feat/ui] 译文行内 CG 专业词库命中高亮**：对命中 Blender / Substance 词库的行业专有名词添加特殊着重色与悬浮卡片注释。
4. **[feat/cache] Translation Memory (TM) 本地持久化缓存**：建立 SQLite / LMDB 轻量级译文数据库，相同文本 0ms 秒开秒查。
5. **[feat/dict] 译文内联编辑与一键加入个人词库**：双击卡片直接修改不准的译文并直接保存至用户自建词典。
