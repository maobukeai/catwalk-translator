# 遗留 Python 版本（已归档）

此目录保存项目早期基于 **PyQt6 + Python** 实现的原型版本。

> ⚠️ **该版本已停止维护**，仅作历史参考。
> 当前主工程请见根目录 `app_v2/`（Tauri 2.0 + Rust + React 19）。

## 文件说明

| 文件 | 说明 |
|------|------|
| `main.py` | Python 版主入口 |
| `core/` | Python 版核心模块（OCR / 翻译 / 覆盖层） |
| `requirements.txt` | Python 依赖列表（PyQt6 / rapidocr / Pillow 等） |
| `启动桌面翻译软件.bat` | 原 PyQt6 版本启动脚本 |
| `启动现代版翻译软件.bat` | 原中间版本启动脚本 |
